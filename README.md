# 🚀 Professional Full-Stack Portfolio | Akhil Kumar

A high-performance, visually stunning portfolio website built with a **React** frontend and a **Django** backend. Featuring interactive 3D animations, glassmorphism design, and a real-time data management system.

## ✨ Key Features

- **📺 Cyberpunk Terminal:** An interactive "About Me" section designed as a Python-IDE with animated neon expertise bars.
- **💎 Project Showcase:** Dynamically filtered project gallery with cinematic cards and hover-tilt effects.
- **🔄 3D Flip Certifications:** Professional certificates from IBM, Oracle, and Cisco displayed on interactive 3D flip cards with brand-colored glows.
- **📱 Social Media Dashboard:** Sleek, brand-coordinated links for YouTube and LinkedIn.
- **🛠️ Admin Panel:** Custom Django Admin integration to manage projects, skills, and contact messages in real-time.
- **⚡ Performance:** Fully responsive design with optimized loading and AOS (Animate On Scroll) transitions.

## 🛠️ Technical Stack

### Frontend
- **Framework:** React.js (v18+)
- **Styling:** CSS3, React-Bootstrap, Glassmorphism
- **Animations:** Framer Motion, AOS, React-Parallax-Tilt
- **Icons:** React Icons (FontAwesome, Simple Icons)

### Backend
- **Framework:** Django (v5+)
- **API:** Django REST Framework
- **Database:** SQLite3 (Scalable to PostgreSQL)
- **Security:** CSRF protection & CORS headers

## 🚀 Getting Started

### 1. Prerequisites
- Python 3.10+
- Node.js & npm

### 2. Backend Setup
```bash
cd backend
python -m venv venv
source venv/bin/activate  # venv\Scripts\activate on Windows
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

### 3. Frontend Setup
```bash
cd frontend
npm install
npm start
```
